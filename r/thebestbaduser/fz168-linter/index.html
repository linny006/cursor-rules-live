# Правила 168-ФЗ

При проверке русских текстов и интерфейсов:

1. Латиница в названии ЖК в рекламе долевого строительства — `LIKELY_VIOLATION`
   по 214-ФЗ п. 7 ст. 2 (введён ст. 4 168-ФЗ). Исключение для товарных знаков
   здесь не действует.
2. Латиница в публичной информации потребителя без русского дубля — вероятное
   нарушение ЗоЗПП ст. 10.1 п. 2. Проверяет Роспотребнадзор, состав —
   ч. 1 ст. 14.8 КоАП (юрлица 5–10 тыс. ₽).
3. Латиница в рекламе — `NEEDS_REVIEW`: ч. 11 ст. 5 38-ФЗ сама по себе не даёт
   основания для дела (приказ ФАС № 1079/23).
4. Не выдумывать штраф 100–500 тыс. ₽ за любое иностранное слово.
5. Товарный знак должен быть зарегистрирован (свидетельство), а не заявлен.
6. Отсутствие слова в нормативном словаре — не запрет, а необходимость пояснения.
7. Смешанные алфавиты (`Пaрк` с латинской `a`) — отдельный признак, проверять
   Unicode-коды.
8. Русский текст при дублировании — первым; цвет, тип, размер шрифта и
   разборчивость должны совпадать (ч. 2 ст. 3 53-ФЗ).
9. Дата переходного исключения неоднозначна: 24.06.2025 (буквально) или
   01.03.2026 (распространённое толкование) — не утверждать без оговорки.

Инструмент проверки: `fz168 check <файл> --input html --surface public_information`.
Документация: `docs/LEGAL.md`, `docs/RULES.md`.
