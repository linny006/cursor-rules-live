# Правила 168-ФЗ

Инструмент универсален: любой русскоязычный текст, UI, документация, реклама,
каталог. Проверка недвижимости — лишь один из контекстов.

При проверке русских текстов и интерфейсов:

1. Если контекст — наименование объекта в рекламе ДДУ: латиница — `LIKELY_VIOLATION`
   по 214-ФЗ п. 7 ст. 2 (введён ст. 4 168-ФЗ). Исключение для товарных знаков
   здесь не действует.
2. Латиница без русского дубля — вероятный риск по ст. 10.1 п. 2 ЗоЗПП только
   после установления применимости статьи. Любой открытый текст сайта не
   становится такой информацией автоматически. Санкции требуют отдельной
   квалификации; линтер их не определяет.
3. Латиница в рекламе — `NEEDS_REVIEW`: ч. 11 ст. 5 38-ФЗ сама по себе не даёт
   основания для дела (приказ ФАС № 1079/23).
4. Не выдумывать штраф 100–500 тыс. ₽ за любое иностранное слово.
5. Исключение товарного знака в API требует `trademark_status=registered`
   и конкретного обозначения в `extra_trademarks`. Заявка недостаточна;
   реестр и иные основания охраны проверяет человек.
6. Локальный список не равен нормативному словарю. Для словарного утверждения
   проверять статью, значение и редакцию. Редакционная рекомендация замены
   не доказывает отсутствия слова или нарушения.
7. Смешанные алфавиты (`Пaрк` с латинской `a`) — отдельный признак, проверять
   Unicode-коды.
8. При дублировании содержание идентично, оформление равнозначно, включая цвет,
   тип и размер шрифта, разборчивость (ч. 2 ст. 3 53-ФЗ). Порядок «русский первым»
   — рекомендация руководства Роспотребнадзора от 02.03.2026.
9. Закон в целом вступил 24.06.2025, статьи 1 и 4 — 01.03.2026. Применимость
   переходного исключения для дат ввода в этом промежутке требует ручной
   проверки. Не представлять политику классификатора как официальное толкование.

Инструмент проверки: `fz168 check <файл> --input html --surface public_information`.
Документация: `docs/LEGAL.md`, `docs/SOURCES.md`, `docs/RULES.md`, `docs/PARSING.md`.
