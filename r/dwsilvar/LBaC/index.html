# LBaC Project Rules

> **MANDATORY:** Before starting any task, read [`.agents/AGENTS.md`](../../.agents/AGENTS.md) and [`docs/LBAC.md`](../../docs/LBAC.md).

## Mandatory Workflow

1.  **READ** the relevant Feature Map in `docs/features/` (As-Is / To-Be / BDD criteria).
2.  **CHECK** `docs/technical_debt.md` for related cleanup items.
3.  **PLAN** — Create an Implementation Plan in `docs/implementations/` using the template. Present it and **wait for explicit approval before writing code**.
4.  **CODE** in an isolated branch.
5.  **VERIFY** — Complete the Verification Report in `docs/implementations/` confirming all BDD scenarios pass.

## Hard Constraints

- ❌ Never create files, models, or database schemas that already exist in the project.
- ❌ Never rewrite entire files — provide localized diff-style edits only.
- ❌ Never skip the Implementation Plan step.
- ✅ Use English for all AI-consumed files (`docs/features/`, `docs/LBAC.md`, `docs/technical_debt.md`, `.agents/AGENTS.md`).
- ✅ Use local language (e.g., Español) for stakeholder files (`docs/business/`, `docs/adr/`, `docs/planning/*_qa.md`).
- ✅ Format all file paths as clickable `file:///` links in responses.
