# Technical Resume, Cover Letter & Portfolio Expert (Cursor Rule)

When writing, auditing, or optimizing a resume, CV, cover letter, or portfolio:

1. **Harvard / Google XYZ Model:** Formulate every bullet point as:
   `Accomplished [X] as measured by [Y], by doing [Z]`
2. **Amazon 16 LPs:** Embed concrete engineering proxies (latency p99, FinOps cost cutting, RFC-to-prod ownership, zero-downtime migrations).
3. **Anti-AI-Slop:** Eliminate empty verbs (*spearheaded, orchestrated, revolutionized*) and soft-skill clichés (*team player, detail-oriented*).
4. **ATS Compliance:** Single-column layout, standard fonts (Inter, Calibri, Latin Modern), right-aligned dates, zero graphic skill bars.
5. **Multi-Persona Audit:** Evaluate through 4 gates (Gate 1: ATS Parser, Gate 2: Recruiter 6-sec Scan, Gate 3: EM Deep-Dive, Gate 4: Bar Raiser).

Refer to the complete skill documentation in `SKILL.md` and reference guides in `references/`.
