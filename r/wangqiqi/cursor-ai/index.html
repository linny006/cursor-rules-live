# 核心

`.cursor/`=通用SOP · `.cursorGrowth/`=项目特化与产出（plan·archive·learn·rules，git忽略）· 读序：rules → config → `.cursorGrowth/`

| 长程 Epic | `/long` → **long**（多 Sprint plan/run 链；单 Sprint 仍用 plan+run） |

## 母版独立 vs 安装后只读

| 场景 | `.cursor/` |
|------|------------|
| **母版仓库**（Super Cursor 模板仓等） | **可自由演进** — 直接改 rules/skills/config/templates |
| **安装到目标项目** | 默认 **只读** SOP；特化 → `.cursorGrowth/`（见下节） |

引用纪律 · 文风 → **cursor-standalone** · `docs/library-index.md`。

## .cursor 不可变（仅 · 安装到目标项目后）

`.cursor/` 自 `install-super-cursor.sh` 复制到**目标项目**后视为 **只读 SOP**，除非用户**明确**要求修改或完善 `.cursor/`：

**母版仓库**不受本条限制（见上节「母版独立」）。

| 禁止（默认） | 允许去向 |
|--------------|----------|
| 主动/自动改 `rules/` `skills/` `agents/` `hooks/` `bin/` `config/` `templates/` | 项目特化 → `.cursorGrowth/`（plan · learn · archive · rules/local） |
| 「顺便优化」模板、补 skill、改 config | 团队 rules → `.cursorGrowth/rules/local/`（链 `.cursor/rules/local`） |
| 因业务任务顺带改 hooks 或 workflow | 行为开关 → 用户自行编辑 `config/*.json`，或明确授权后由 Agent 改 |

发现缺口：**说明 + 建议**，等用户确认后再动 **目标项目**的 `.cursor/`。母版仓库日常 Sprint **可直接改**。目标项目 `/master` `/plan` `/run` `/learn` **不得**触发对 `.cursor/` 的写入。

## 沟通

**语言与用户一致**：用户用中文提问/发任务 → 思考与回复用中文；用户用英文 → 思考与回复用英文。同一会话以**最新一条用户消息**为准；混合语言时跟用户主要用语。

不清先问 · 小 diff · 引用行号 · 中途改向=steering（非取消，除非明确取消）

## 安全

无密钥 · 默认禁止 force-push / 跳 hook · delete/reset 须确认 · 批量新建前先 `/plan`

## 审计

人定目标 · 结论可验证 · 动作可重建
