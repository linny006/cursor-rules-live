# AI Agent Rules — REPLACE:PROJECT_NAME

> **Bootstrap:** copy `templates/cursorrules.template` → repo-root `.cursorrules`, then replace every `REPLACE:` token.

## Core Principles (ALWAYS APPLY — override all else, non-negotiable)

1. **Correct the user.** Be truthful; never agree to be agreeable. If an approach is flawed, say so and offer a better path.
2. **Never claim PASS on failing output.** Report any test/build/validation error explicitly with the relevant output.
3. **Verify before "done".** Run tests/build/lint appropriate to the change; all provided tests must pass. If you can't verify, state what you checked and what's unverified.
4. **Optimal path.** Most efficient, reliable, maintainable option; no over-engineering; no edits to unrelated files.
5. **Evidence-first, never memory-first.** Back every non-trivial claim with file evidence (path + snippet), runtime output, or live docs. Missing evidence → mark **Unverified** and gather it. Banned without evidence: "this is fixed", "already implemented", "tests pass", "works now".
6. **Assumption ledger** (substantial tasks): state Confirmed facts / Inferences / Unknowns; never collapse inference into fact.
7. **Completion gate** (cannot skip): claim done only when changes are applied, checks ran, output shows no blocking failure, and residual risks are listed. If checks can't run, say why + give manual steps.

## Change safety (mechanical)

Default to **minimal diffs**. Run before commit / `@code-implementation complete`:

| Gate | Command | Fail when |
|------|---------|-----------|
| Touch scope | `bash scripts/touch-scope-verify.sh` | File outside `.work/touch-scope` or iteration **Files** |
| Blast radius | `bash scripts/blast-radius-check.sh` | `risk: high` (cross-area or oversized diff) |
| Protected surfaces | `standards/PROTECTED_SURFACES.json` + `.work/PROTECTED_SURFACES.json` + §Protected Files | High-blast path without owner approval |
| Tests | `bash scripts/framework-verify.sh` (see `DOCS_TECH_STACK.md`) | Non-zero exit |

**Declare scope first:** copy `templates/work/touch-scope.template` → `.work/touch-scope`, or `@code-implementation plan` with **Files** per task. **MOD-06** required for agent-authored code (`concepts/README.md` § Trigger table); `human-only` opt-out only when the human declares it in the same message. **No collateral edits** — no drive-by refactors, dependency bumps, or "while I'm here" changes.

Sister frameworks are siblings on disk; `.ai/` is self (self-hosted). Paths resolve at runtime.

| `.ai.biz` (Business OS) | `@biz-director` | `../.ai.biz` | `../.ai.biz/skills/README.md` |
| `.ai.soc` (Social OS) | `@soc-director` | `../.ai.soc` | `../.ai.soc/skills/README.md` |

**Path resolution:** (1) use a filled path cell; empty → fall through. (2) Auto-discover: fat-client parent = `$REPO_ROOT/.ai/..`; thin-client parent = `$AGENT_OS_SOURCE/..`; check `${parent}/.ai.ui|.ai.biz|.ai.soc`; missing = "not installed". (3) Before routing, verify the framework dir + its `skills/README.md` exist; if absent, route to `@ai-director` prefixed `[degraded: <framework> not installed]` — never route into the void.
