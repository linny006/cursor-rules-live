# MAWYXX PRIME — MANDATORY BOOT

You operate in **PRIME mode** for every task. The MAWYXX PRIME standard is the
single source of truth. If your habits or guesses conflict with the standard —
**the standard wins**. Never write code before steps 1–3 are done.

---

## STEP 3 — SIMULATE every point on the REAL task (mandatory)

This is **not a checklist**. For every point below, mentally run it **on this
exact task** and write a short, concrete trace. One-word answers ("yes", "ok",
"n/a") are rejected. If you cannot simulate a point concretely → mark
`INVESTIGATE(reason)` and resolve it (repo / tests / data) — do not guess.

**3.1 Tier** — why THIS tier for THIS task (which triggers fire, why not lower/higher); what follows (coverage, mutation, test families).

**3.2 Default-secure 5Q** — for each of the five, describe a **concrete hostile input** to the actual operation and what stops it (name the real field / route / resource).

**3.3 Laws** — for each applicable `A-xx`: say what it changes **here** — where the port goes, where the transaction boundary is, the exact `Err` variant, the index, the authz owner. Not applicable → give the absent When-trigger.

**3.4 Maps** — actually draft them: real port names; taxonomy families with **real test names**; trust pipeline steps for **real ops**; AC with **observable oracles**; concrete `blast_radius` files.

**3.5 Gates** — for each gate you will be checked by: what it will parse in **your** files and **what it would flag**. Do not just list gate names.

**3.6 Conflict Matrix / uncertainty** — name the exact tension for THIS task (when-trigger vs YAGNI vs blast vs A40/A41) and the side you choose.

**3.7 Reasoning 8 steps (§1.10)** — fill with real content: **FIT** (why the rule's premises hold here), **ALT** (a real alternative you rejected and why).

**3.8 Adversarial 8 questions (§4.14)** — for EACH question, simulate the concrete scenario and name the **test or gate** that closes it (never "covered"):
`×1000 input` → which test · `double call` → which idempotency test · `parallel` → which concurrency test · `dep down` → which fallback test · `empty/null` → which test · `hostile user` → cross-user/IDOR test · `prod` → which guard · `if I'm wrong` → which gate proves it.

**3.9 End-to-end trace** — walk ONE real request/flow through the layers: source → schema → authn → authz(resource) → command → UC → sink → response. Then walk the **failure / retry / concurrency** variant of the same flow.

**3.10 Data & volume** — simulate 0, 1, 100, 1 000 000 rows/items; N+1; index hit/miss; cold cache; oversized payload.

**3.11 Failure** — simulate DB down, Redis down, third-party slow/timeout, queue backlog, crash between steps.

**3.12 Time & concurrency** — simulate two parallel calls, retry with the same key, out-of-order/duplicate webhook, clock/TZ edge.

Output the result as a compact **Simulation trace** (bullets) **before writing code**. Re-simulate whenever the task changes.

## STEP 4 — Work the phases

```
PHASE 0    Tier + adoption_mode + Domain Elicitation (§1.12)
PHASE 0.5  Design Artifact + 5Q + Threat Model 10Q + maps + AC oracles + blast
PHASE 1–3  Research → TDD-lock → ports → adapters → composition root
PHASE 4    Fix-until-green (P0 → P1 → P2)
PHASE 4.5–4.8 Guardian audit + review + Two-Agent adversarial
PHASE 5    prime_check FULL + evidence block
```
Sub-agents per §1.11 when applicable (Writer ≠ Verifier).

## STEP 5 — Always with the standard

- **Law→Gate**: every MUST maps to a real gate.
- **Anti-N/A**: `N/A(reason)` only; never a naked `N/A`.
- **fix-until-green**: never stop with `exit ≠ 0`; never ask the user to run tests.
- **Evidence** (§3.5) before saying "done"; coverage alone ≠ done.
- **Self-Sufficiency** (§4.17): decide and verify everything yourself.
- Gate missing → bootstrap per §3.2 (**FOCUS 30** → CORE 70 → FULL).

## STEP 6 — Never

- Code before the standard is loaded **and** every point simulated.
- Tick the simulation without concretely running it.
- Claim done while `prime_check` is red or without evidence.
- Invent rules — if the standard is unclear, use the Conflict Matrix, then the stricter reading.

If download of the standard fails — retry once via
`https://github.com/Mawyxx/Mawyxx-Prime/blob/main/Mawyxx%20Prime%20V6.5.md`,
then stop and report the blocker with that link.
